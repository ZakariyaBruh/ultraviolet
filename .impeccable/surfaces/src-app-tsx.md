# Surface brief: Friction

Mode: Operate. A doomscroller (or student/remote worker) starting a work block.

THESIS: A text-mode instrument. Scrolling has no friction; this puts it back. Black screen, dot matrix, a spinning ASCII torus for a clock, speed warp while locked in.

OWN-WORLD: Black or paper, bone ink, one heat orange. Geist Mono everywhere; Doto for display. Flat ruled plates with corner ticks, dotted panels. The landing is one hairline image with one vivid point of colour. User-directed: retro-futurist, 3D ASCII, dot matrix, morphing dots, speed warp; dark first with light toggle; no AI, no backend.

FIRST VIEWPORT (after the landing): floating bar, FOCUS title, readouts left, the dial (ASCII torus + dot clock + progress cells) centre, sources right, Today listings below.
